# Native tools

- [aggrescan3d-rs](aggrescan3d-rs/README.md): static structure-based aggregation scoring with pinned FreeSASA accessibility, numerical regression fixtures and upstream parity checks.

Build products and downloaded source stay under gitignored `.tools/`. Install with [the optional native installer](../install/install-aggrescan3d.sh); configure and review results with [the usage guide](../docs/usage/aggrescan3d-rust.md).

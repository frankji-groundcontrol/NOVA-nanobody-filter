# Upstream numerical fixture

[upstream-scoring.csv](upstream-scoring.csv) contains expected residue scores generated by the unmodified pinned upstream core. It covers all 20 amino acids; RSA values 0, 9.9, 10, 54.9, 55, 55.1 and 80%; radii 5 and 10 Å; and the default scale plus pH 4, 7 and 10.

Consumer: [native scoring tests](../tests/scoring.rs). The [upstream parity harness](../tools/upstream_parity.py) can regenerate it using `--fixture OUTPUT.csv`; review changes against the pinned source and matrix checksums. Synthetic coordinates exercise numerical boundaries and are not a biological validation dataset.

Parent: [scorer guide](../README.md). Next: retain unchanged expected values unless the scientific method intentionally changes.
